# Fitness-Master — Product showcase
Responsive static one-page site for Operation 24/7. No build step or dependencies. Open `index.html` locally with the `assets` directory alongside it, or serve with `python3 -m http.server 8080`.

## GitHub Pages
Upload all contents of this directory (not the enclosing directory) to the root of `Julkar100/Health-Master-Website`. Commit to `main`, then Settings → Pages → Deploy from a branch → main → / (root). Expected address after successful deployment: https://julkar100.github.io/Health-Master-Website/.

This is a product showcase, not an operational gym application. Screenshots and metrics are illustrative; technology and features are proposed. Verify external link access before submission. No private API credentials or actual member records are included.
